## Cross-lingual Embedding Analysis

### 1. Model Performance
The `bert-base-multilingual-cased` model demonstrated a high capability in capturing semantic meaning across English and Arabic. The heatmap shows significant similarity scores between translated pairs, proving that the model aligns different languages into a shared conceptual space.

### 2. Implications for MENA Region
Using a single multilingual model instead of separate models for each language is a game-changer for the MENA region. It allows for building cross-lingual search engines and classification tools that can understand Arabic queries and retrieve English documents (or vice-versa) efficiently, reducing the need for massive translation pipelines.
